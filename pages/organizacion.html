🧩 Organización de los Sistemas Operativos

Componentes, modo dual y estructura interna.

Componentes del SO

El SO se compone de varias capas que trabajan juntas:

  • Gestión de procesos
  • Gestión de memoria
  • Gestión de archivos
  • Gestión de E/S
  • Redes y seguridad

Modo dual (Kernel / Usuario)

La CPU alterna entre dos modos para proteger el sistema:

  • Modo kernel: acceso total al hardware
  • Modo usuario: acceso restringido, las peticiones pasan por system calls

Estructura del SO

  • Monolítico: todo el kernel en un solo bloque (Linux)
  • Microkernel: servicios mínimos en kernel, el resto en usuario (QNX)
  • Híbrido: mezcla de ambos (Windows, macOS)
