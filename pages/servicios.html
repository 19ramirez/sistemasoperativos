⭐ Servicios del Sistema Operativo

El contrato entre tus programas y la máquina. Explicación visual con ejemplos reales de la interfaz de programación.

El sistema operativo es el intermediario entre el hardware y los programas. No puedes hablar directamente con el disco, la memoria o la red: necesitas servicios que el SO te ofrece.

👉 Haz clic en cada tarjeta para ver un ejemplo de cómo un programa usa ese servicio.

🪟

Interfaz de Usuario

CLI, GUI, batch…

El SO te da una forma de comunicarte con él. Sin interfaz, la computadora sería inutilizable para humanos.

# Ejemplo: shell de Linux
$ ls -la
$ mkdir proyecto
$ python main.py

🔌 Interfaz de programación: los programas usan system(), exec() o APIs gráficas (Win32, Cocoa) para interactuar con el usuario.

💾

Operaciones de E/S

Leer/escribir archivos y dispositivos

Los programas no pueden tocar el disco directamente. El SO gestiona las operaciones de entrada/salida por seguridad y eficiencia.

// C: abrir un archivo
FILE *f = fopen("datos.txt", "r");
if (f) {
    char buffer[100];
    fgets(buffer, 100, f);
    fclose(f);
}

🔌 Interfaz de programación: open(), read(), write(), close() son llamadas al sistema.

📁

Gestión de Archivos

Crear, borrar, buscar, listar

El SO organiza el almacenamiento en archivos y directorios. Los programas piden operaciones por nombre, no por sectores del disco.

# Python: manipular archivos
import os
os.makedirs("proyecto/src", exist_ok=True)
with open("proyecto/README.md", "w") as f:
    f.write("# Mi proyecto")
print(os.listdir("proyecto"))

🔌 Interfaz de programación: las librerías estándar (os en Python, File en Java, fstream en C++) envuelven las llamadas al sistema.

🌐

Comunicaciones

Procesos que hablan entre sí

Los procesos necesitan intercambiar datos, ya sea en la misma máquina (pipes, sockets locales) o por red (TCP/IP).

# Python: dos procesos se comunican
import socket
s = socket.socket()
s.bind(('localhost', 12345))
s.listen()
conn, _ = s.accept()
print("Recibido:", conn.recv(1024).decode())

🔌 Interfaz de programación: socket(), send(), recv(); o abstracciones como requests en Python.

⚠️

Detección de Errores

El SO te avisa cuando algo sale mal

Errores de hardware, de E/S, divisiones por cero, accesos ilegales a memoria. El SO los detecta y toma acción.

# Python: manejo de errores de E/S
try:
    with open("no_existe.txt") as f:
        contenido = f.read()
except FileNotFoundError:
    print("El SO reportó: archivo no encontrado")

🔌 Interfaz de programación: excepciones, códigos de error (errno en C), try/except en lenguajes modernos.

⚙️

Asignación de Recursos

CPU, memoria, dispositivos

Cuando varios programas compiten por CPU o RAM, el SO decide quién obtiene qué y cuándo.

# Python: crear un proceso (el SO le asigna CPU)
import multiprocessing

def tarea(n):
    print(f"Proceso {n} ejecutándose")

if __name__ == "__main__":
    procesos = [multiprocessing.Process(target=tarea, args=(i,)) for i in range(3)]
    for p in procesos: p.start()
    for p in procesos: p.join()

🔌 Interfaz de programación: fork(), CreateProcess(), multiprocessing en Python.

🔁 Así fluye una petición de servicio

📱Tu programa
→
📚Librería estándar
(ej. open())
→
🔔Llamada al sistema
(system call)
→
🖥️Sistema Operativo
(gestor de archivos)
→
💽Hardware
(disco, memoria…)

Los programas nunca hablan directamente con el hardware. Siempre pasan por el SO mediante llamadas al sistema.
